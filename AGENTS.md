# Development instructions

- This repository remains public by explicit user decision. Never commit credentials, private configuration, signing keys, private data, or personal machine paths.
- Read README.md, HANDOFF.md and DEVELOPMENT_NOTES.md before work.
- Check the current branch, dirty state and remote divergence before synchronization. Preserve all experiment branches and local changes.
- Do not overwrite another computer's work or use destructive Git commands or force push.
- Keep collection workflows, data and Pages running. A documentation migration does not authorize production deployment, workflow changes or model retraining.
- Review intended changes, run relevant checks, record actual results and update the handoff before committing and pushing.
- Git carries files and documented context; it does not synchronize chat history.
